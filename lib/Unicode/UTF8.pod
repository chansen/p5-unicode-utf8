=head1 NAME

Unicode::UTF8 - Encoding and decoding of UTF-8 encoding form

=head1 SYNOPSIS

    use Unicode::UTF8 qw[ decode_utf8 encode_utf8 valid_utf8
                          read_utf8 slurp_utf8 ];

    $string = decode_utf8($octets);
    $octets = encode_utf8($string);

    $boolean = valid_utf8($octets);

    $count  = read_utf8($fh, $buf, $length);
    $string = slurp_utf8($filename);

    # throw an exception instead of substituting U+FFFD
    use warnings FATAL => 'utf8';

=head1 DESCRIPTION

This module encodes and decodes the UTF-8 encoding form as specified by the
Unicode Standard and ISO/IEC 10646.

It is strict: only well-formed UTF-8 is accepted when decoding, and only
well-formed UTF-8 is produced when encoding. Non-shortest forms, surrogates
(U+D800..U+DFFF) and code points above U+10FFFF are never passed through.
Noncharacters are allowed and receive no special handling.

=head2 Error handling

Input that cannot be decoded or encoded is not fatal by default. Each
offending sequence or code point is replaced with REPLACEMENT CHARACTER
(U+FFFD) and reported with a warning in the C<utf8> category. These warnings
are enabled by default, also without C<use warnings>.

    no warnings 'utf8';             # substitute silently
    use warnings FATAL => 'utf8';   # throw an exception instead

C<decode_utf8> and C<encode_utf8> also accept a C<$fallback> that chooses
the replacement.

=head1 FUNCTIONS

=head2 decode_utf8

    $string = decode_utf8($octets);
    $string = decode_utf8($octets, $fallback);

Decodes C<$octets>, a string of UTF-8 encoded octets, and returns the
resulting character string.

Each ill-formed sequence is replaced with U+FFFD and reported with a warning
(see L</Error handling>). One U+FFFD is substituted for each I<maximal
subpart> of an ill-formed sequence, which is the practice recommended by
Unicode: the longest run of octets that could begin a well-formed sequence,
or otherwise a single octet.

    Octets           Decoded as              Reason
    <E2 82 AC>       U+20AC
    <80>             U+FFFD                  unexpected continuation octet
    <E2 82>          U+FFFD                  truncated sequence
    <C0 80>          U+FFFD U+FFFD           non-shortest form
    <ED A0 80>       U+FFFD U+FFFD U+FFFD    surrogate (U+D800)
    <F4 90 80 80>    U+FFFD (four times)     above U+10FFFF

Throws an exception if C<$octets> contains a wide character (a code point
above 0xFF), since it is then not a string of octets.

C<$fallback> is an optional C<CODE> reference that is called for each
ill-formed sequence. Its return value is used in place of U+FFFD.

    $replacement = $fallback->($octets, $is_usv, $position);

=over 4

=item C<$octets>

The maximal subpart of the ill-formed sequence, one to three octets.

=item C<$is_usv>

Always false. Kept for backwards compatibility: before version 0.64 it was
true when the fallback was invoked for a noncharacter.

=item C<$position>

The zero-based octet offset of the sequence within the string given to
C<decode_utf8>.

=back

C<$fallback> must return a character string of zero or more Unicode scalar
values (code points in the range U+0000..U+D7FF and U+E000..U+10FFFF). The
returned string is inserted as is and is not validated.

The warning is issued before C<$fallback> is called, so C<$fallback> is
normally used together with C<no warnings 'utf8'>. If the warning is fatal,
C<$fallback> is not called.

    no warnings 'utf8';

    # remove ill-formed sequences
    $string = decode_utf8($octets, sub { '' });

    # interpret the octets of ill-formed sequences as ISO-8859-1
    $string = decode_utf8($octets, sub { $_[0] });

    # show the octets of ill-formed sequences as hexadecimal escapes
    $string = decode_utf8($octets, sub {
        join '', map { sprintf '\x%.2X', ord } split //, $_[0];
    });

=head2 encode_utf8

    $octets = encode_utf8($string);
    $octets = encode_utf8($string, $fallback);

Encodes C<$string>, a character string, as UTF-8 and returns the resulting
string of octets.

Every Unicode scalar value is encoded. A code point that cannot be
represented in the UTF-8 encoding form is replaced with U+FFFD and reported
with a warning (see L</Error handling>). These are the surrogates
(U+D800..U+DFFF) and the code points above U+10FFFF, which only exist in
Perl's extended code space.

    Code point       Encoded as              Reason
    U+20AC           <E2 82 AC>
    U+FFFE           <EF BF BE>              noncharacter, allowed
    U+D800           <EF BF BD>              surrogate
    0x110000         <EF BF BD>              above U+10FFFF

The warnings are issued in the C<utf8> category. On Perl 5.14 or later they
can also be controlled with its sub-categories C<surrogate> and
C<non_unicode>.

C<$fallback> is an optional C<CODE> reference that is called for each code
point that cannot be represented. Its return value is encoded in place of
U+FFFD.

    $replacement = $fallback->($codepoint, $is_usv, $position);

=over 4

=item C<$codepoint>

The code point that cannot be represented, as an unsigned integer.

=item C<$is_usv>

Always false. Kept for backwards compatibility: before version 0.64 it was
true when the fallback was invoked for a noncharacter.

=item C<$position>

The zero-based character offset of the code point within the string given to
C<encode_utf8>.

=back

C<$fallback> must return a character string of zero or more Unicode scalar
values (code points in the range U+0000..U+D7FF and U+E000..U+10FFFF). The
returned string is encoded as is and is not validated.

The warning is issued before C<$fallback> is called, so C<$fallback> is
normally used together with C<no warnings 'utf8'>. If the warning is fatal,
C<$fallback> is not called.

    no warnings 'utf8';

    # remove code points that cannot be represented
    $octets = encode_utf8($string, sub { '' });

    # show them as Perl escapes
    $octets = encode_utf8($string, sub { sprintf '\x{%X}', $_[0] });

Throws an exception if Perl's internal representation of C<$string> is
ill-formed.

=head2 read_utf8

    $count = read_utf8($fh, $buf, $length);
    $count = read_utf8($fh, $buf, $length, $offset);

Reads up to C<$length> UTF-8 encoded characters (code points) from the file handle
C<$fh>, decoding and validating them in place, and stores the result in C<$buf>.
Returns the number of characters actually read, C<0> at end of file, or C<undef>
on a read error (with C<$!> set).

Because C<read_utf8> reads and validates the octets directly, there is no need to
apply a PerlIO encoding layer (such as C<:encoding(UTF-8)> or C<:utf8>) to C<$fh>.
The handle should be a plain byte handle; the bytes are validated and decoded by
C<read_utf8> itself.

If C<$offset> is specified, the read data is written into C<$buf> starting at that
character offset, preserving the existing content before it. A negative C<$offset>
counts back from the end of C<$buf>. If the offset is past the end of the string,
C<$buf> is zero-filled up to the offset first.

Ill-formed and truncated input is not fatal: each maximal ill-formed subpart is
replaced with the Unicode replacement character U+FFFD and a warning is emitted in
the C<utf8> warnings category. The returned count includes the substituted code
points.

Tied file handles are not supported.

Since version 0.71.

=head2 slurp_utf8

    $string = slurp_utf8($filename);

Reads the entire file named C<$filename> and returns its contents decoded from
UTF-8 as a character string. The file is read using unbuffered (C<:unix>) IO,
and the octets are validated and decoded directly.

There is no upper bound on the amount read; the whole file is loaded into
memory. When handling untrusted or potentially large files, check the size
first (for example with C<-s $filename>) before calling C<slurp_utf8>.

Ill-formed and truncated input is not fatal: each maximal ill-formed subpart is
replaced with the Unicode replacement character U+FFFD and a warning is emitted in
the C<utf8> warnings category.

C<$filename> must be a string of octets. Throws an exception if it contains a
wide character or C<"\0">, or if the file cannot be opened or read.

Since version 0.73.

=head2 valid_utf8

    $boolean = valid_utf8($octets);

Returns a boolean indicating whether or not C<$octets> consists of
well-formed UTF-8 sequences. No warnings are issued.

Throws an exception if C<$octets> contains a wide character.

Since version 0.60.

=head1 EXPORTS

None by default. All functions can be exported using the C<:all> tag or individually.

=head1 DIAGNOSTICS

=over 4

=item Can't decode a wide character string

(F) The C<$octets> given to C<decode_utf8> contain a code point above 0xFF.

=item Can't validate a wide character string

(F) The C<$octets> given to C<valid_utf8> contain a code point above 0xFF.

=item Can't decode ill-formed UTF-8 octet sequence <%s> in position %u

(W utf8) C<decode_utf8> encountered an ill-formed UTF-8 octet sequence. <%s>
contains a hexadecimal representation of the maximal subpart of the
ill-formed sequence, and %u is its octet offset.

=item Can't decode ill-formed UTF-8 octet sequence <%s>

=item Can't decode ill-formed UTF-8 octet sequence <%s> at end of file

(W utf8) C<read_utf8> or C<slurp_utf8> encountered an ill-formed UTF-8 octet
sequence. The second form is used for a sequence that is cut short by the
end of the file.

=item Can't represent surrogate code point U+%X in position %u

(W utf8, surrogate) Surrogate code points are designated only for surrogate code
units in the UTF-16 character encoding form. Surrogates consist of code points
in the range U+D800 to U+DFFF.

=item Can't represent super code point \x{%X} in position %u

(W utf8, non_unicode) Code points greater than U+10FFFF. Perl's extended codespace.

=item Can't decode ill-formed UTF-X octet sequence <%s> in position %u

(F) Encountered an ill-formed octet sequence in Perl's internal representation
of wide characters.

=item Negative length

=item Offset outside string

(F) The C<$length> or C<$offset> given to C<read_utf8> is out of range.

=item Couldn't open '%s': %s

=item Couldn't read '%s': %s

(F) C<slurp_utf8> could not open or read the file.

=item Wide character in filename

=item Invalid \0 character in filename

(F) The C<$filename> given to C<slurp_utf8> is not a usable string of octets.

=back

The sub-categories C<surrogate> and C<non_unicode> are only available on Perl
5.14 or later. See L<perllexwarn> for available categories and hierarchies.

=head1 COMPARISON

Here is a summary of features for comparison with L<Encode>'s UTF-8 implementation:

=over 4

=item *

Simple API which makes use of Perl's standard warning categories.

=item *

Implements Unicode's recommended practice for using U+FFFD.

=item *

Better diagnostics in warning messages

=item *

Detects and reports inconsistency in Perl's internal representation of
wide characters (UTF-X)

=item *

Preserves taintedness of decoded C<$octets> or encoded C<$string>

=item *

Better performance ~ 600% - 1200% (JA: 600%, AR: 700%, SV: 900%, EN: 1200%,
see benchmarks directory in git repository)

=back

=head1 CONFORMANCE

It's the author's belief that this UTF-8 implementation is conformant with
the Unicode Standard Version 6.0. Any deviations from the Unicode Standard
is to be considered a bug.
